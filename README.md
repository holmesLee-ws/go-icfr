# go-icfr

내부회계관리제도(재무보고 내부통제, ICFR)를 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 외부감사법과 국내 평가·보고 기준을 뼈대로 하고, COSO·SOX·PCAOB AS 2201 같은 해외 기준을 비교 축으로 씁니다. 마지막에는 내 회사의 업무 프로세스 하나로 위험통제매트릭스(RCM)와 평가 초안을 만듭니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도, 법령·기준의 근거 대장, 튜터의 행동 규칙만 있습니다. 도식과 조사 자료를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

> 학습용입니다. 우리 회사가 대상인지, 어떤 미비점이 중요한 취약점인지 같은 실제 판단은 회사의 감사인·법률 자문과 확인하세요. 법령·기준은 개정되므로 튜터는 적용 시기가 바뀌는 항목을 세션 중에 공식 출처로 다시 확인합니다.

## 시작하기

준비물은 [Git](https://git-scm.com/downloads), [GitHub CLI](https://cli.github.com)(`gh`), [Claude Code](https://code.claude.com/docs) 또는 Claude Desktop입니다. Windows에서는 Git for Windows를 먼저 설치해야 Claude Code가 동작합니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 시작하는 데 다른 설치는 필요 없습니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-icfr
```

**Claude Code**

```bash
cd ~/Desktop/go-icfr
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Desktop으로 하더라도 위의 클론은 터미널에서 먼저 해 둡니다. 그다음 Code 탭에서 데스크탑의 `go-icfr` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

터미널은 macOS에서 Spotlight(⌘+Space)에 「터미널」을 쳐서 열고, Windows에서는 시작 메뉴의 PowerShell을 씁니다. Windows에서 바탕화면이 OneDrive로 옮겨져 있으면 `~/Desktop` 대신 `~/OneDrive/Desktop`(또는 원하는 아무 폴더)에 클론하세요.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 회계·감사·통제 경험은 어떤지 짧게 묻고, 영역(기초·제도·설계·평가)마다 상황 문제를 하나씩 풀어 출발점을 찾습니다. 처음이면 이 단계는 생략합니다.
2. 모듈마다 먼저 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답을 반영한 HTML을 만들어 가며 익힙니다. RCM·평가표 같은 산출물은 `learner/lab/`에 함께 채웁니다. 회사 이름·실제 금액·사람 이름은 넣지 말고 가명과 범위로 말해 주세요.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역 F·L·D·E]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도 |
| [curriculum/sources.md](curriculum/sources.md) | 법령·기준 근거 대장(공식 URL·조회일) |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내 산출물. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/lab`의 산출물을 쓰고, 웹(법령·기준 공식 출처)을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고치거나 명령을 실행할 때는 평소처럼 허락을 구합니다. 대화 내용은 Claude 서비스로 전송되고, 웹 조사 때는 질문과 주소가 외부 사이트로도 전달됩니다. 그래서 회사 이름·실제 금액·사람 이름·내부 문서 원문은 대화에 넣지 말고 가명과 범위로 말해 주세요.

## 관련 워크스페이스

전사 위험관리·내부감사·준법 통제 총론은 go-control, 계정별 회계처리는 go-accounting, 월 결산·예산·경영 보고는 go-controllership, 정보보호는 go-security에서 다룹니다. 이 리포는 그 주제를 재무보고 통제에 필요한 만큼만 다룹니다.
